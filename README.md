# Tu CM · portal del cliente

App web (celular y compu) para que cada cliente revise y apruebe su semana de Instagram, mande fotos y mensajes y complete su alta. Los datos viven en el puente de Google del servicio; este repo solo tiene la interfaz.

- Acceso: `https://solbrandalisse22.github.io/cm-portal/?c=<clave-del-cliente>`
- Demo sin datos reales: `?demo=1`
